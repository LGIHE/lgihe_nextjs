# Assets Directory

## Logo Instructions

Place your LGIHE logo image in this directory with the name:
- `logo.png` or `logo.svg`

The logo will be automatically displayed in the navigation bar.

Recommended dimensions: 150px width x 60px height (or similar aspect ratio)

## Images Directory

All images for the website should be placed in the `/public/images/` directory.

See `/public/images/README.md` for detailed information about required images including:
- Hero carousel images (3 images)
- Staff and team photos
- Founders/Board member photos
- Campus and facility images
- Program images

## Important Notes

- Images are optimized using Next.js Image component
- Placeholders are shown until actual images are added
- All images should be web-optimized (under 500KB recommended)
- Supported formats: JPG, PNG, WebP
